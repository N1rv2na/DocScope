全体题目中 1,604 道事实完整映射，651 道未能可靠映射，301 道是 `null_query`；后两类不进入片段覆盖分母，`null_query` 也不进入文章召回分母。未映射事实原因共 691 次 `no_chunk`、1 次 `ambiguous_chunks`；一个问题可以有多个失败事实。人工检查了数条匹配和失败样例：至少一个 `no_chunk` 的事实存在于整篇正文，但跨越标准 1,000 字符 Chunk 边界，因此当前规则不能把它记为片段命中。映射失败不是检索失败。文章级和片段级指标分别计算，没有把文章命中替代事实命中。

固定 12 道 dev 答案题均运行：7 次 HTTP 200（其中 1 次回答、6 次拒答），5 次 HTTP 502 `model_output_invalid`，因为模型输出不完整。这些错误仍保留在逐题结果中，不能当作正确回答，也不能将这 12 题称为全量答案成绩。12 次请求均返回模型标识 `loomy/DeepSeek-V4.1-Flash`；请求模型为 `group/docscope-free`，网关内部真实渠道无法进一步独立审计。API usage 合计 prompt 20,322、completion 3,479 Token。网关未提供可核验的账单金额，`billed_cost_cny` 保留为 `null`，并非零费用。

总流程 427.146 秒，包含模型加载、文章摄取、检索和 12 次远程调用。逐题检索耗时中位数 0.016 秒、P95 约 0.020 秒，最大值 16.035 秒包含临时连接超时重试；这些是本机单次运行观测，不代表长期服务时延。运行前曾因超长问题 API 限制和本地 Qdrant 连接超时中断；正式产物来自修复后的完整运行。运行结束后隔离集合已清理。

封存 test 是 DocScope 自建划分，不是上游官方测试集。本次没有根据 test 成绩修改配置，也没有运行 BM25、Rerank 或 Agent 对照。回答错误和跨 Chunk 映射失败是后续优化线索，不能据此宣称 Dense 基线以外技术的提升。
