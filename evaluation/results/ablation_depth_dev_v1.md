## 判断与限制

扩大候选池出现覆盖退化；现阶段保持默认 Top-5，不建议直接切换到 Top-8 或 Top-10。

本文是冻结 dev 子集上的检索与证据选择离线比较；仅 12 道官方 dev 题加 2 道自建无证据题，不代表完整 Benchmark。文章覆盖与仅对唯一映射事实计算的事实覆盖分开报告。
候选池扩大后可能恢复单轮丢失的证据，也可能仍被最终 Top-5 排除；逐题 JSON 包含全部排名和流失阶段，不能把进入候选池直接算作最终覆盖。
没有新的 Answer 或引用结果，不能据此声称回答质量改善；Planner 查询保持历史轨迹，也不能据此声称动态规划能力改善。下一步只在覆盖收益明确且退化可接受时，另行授权真实 Answer 对照；否则保持默认 Top-5。
