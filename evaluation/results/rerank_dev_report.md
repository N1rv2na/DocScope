# DOCS-010：Dense / Hybrid / Cross-Encoder 检索消融

2026-10-30 在本地 CPU 与 Qdrant 1.20.0 实测。[固定配置](../configs/rerank_dev_v1.json)使用 MultiHop-RAG 的 609 篇文章和冻结 `dev` 的全部 2,045 道题，未使用封存 `test` 调参或报告成绩，也未调用远程 LLM。完整逐题排序、事实映射、阶段分数与延迟见[原始 JSON](rerank_dev_v1.json)。

三组共用同一批 Chunk、Embedding 和题目。A 为 Dense Top-10；B 为 Qdrant 原生 BM25 + Dense 两路各 Top-20、RRF Top-20 后直接取前 10；C 对**同一份** RRF Top-20 候选用本地 `cross-encoder/ms-marco-MiniLM-L6-v2`（revision `233902d25c440f23af6f7d6e94d2946bac0bee0a`）重新排序，再取前 10。查询 A/B 的先后按题交错，C 的 CPU 打分在两路查询完成后执行。C 保留原 RRF 排名与分数，并另列 Cross-Encoder 原始分数；两类分数不可直接比较。

C 单独的 CPU 重排阶段中位数 384.2 ms、P95 460.2 ms；完整流程耗时 1,274.6 s，包含摄取、模型加载、事实映射与全部查询。约 16 s 的异常长检索与本地连接超时/重试量级相符，不能把均值当作稳定服务延迟。模型首次在本机冒烟时加载约 58.6 s，预热后 20 条重复短候选约 0.13 s；正式长文本候选的真实时延以上表为准。无 GPU、远程模型或 LLM 费用。

本轮 C 相比 B **退化**：文章 Recall@5 从 0.6064 降至 0.5361，Fact Coverage@5 从 0.4252 降至 0.3555。逐题仍有改善：文章 Recall@5 为 291 题改善、576 题下降、937 题不变；Fact Coverage@5 为 180 题改善、399 题下降、703 题不变。例：`mhr-q-00eff67bdad0c6d794d3` 的一个已映射事实在 B 排名第 1，C 的 Top-10 中消失，Fact Coverage@5 从 1/3 降为 0；同题文章 Recall@10 却从 2/3 升为 1，说明文章命中不能替代片段支持。改善例 `mhr-q-000b7e948af39a1f60f8` 中，B 排名第 9 和 16 的两个事实 Chunk 被 C 提到第 1 和第 6，Fact Coverage@10 从 1/4 升到 2/4。两例的来源 ID、RRF 名次、重排分数和指标均可在逐题 JSON 中复核。

验证：样本 ID 与冻结 dev 清单完全相同；每题 C 的候选数为 20、输出不超过 10，稳定来源 ID 无重复，C 中 RRF 名次 1–20 且分数有限；前 10 名的 RRF 名次可与 B 排名核对；A 与 DOCS-009 逐题指标一致；A/B 查询顺序分别出现 1,023/1,022 次。隔离 Qdrant 集合已清理。这个结果只支持本配置在开发集上的检索结论；不证明 Cross-Encoder 对其他数据、回答质量或 Agent 有益。
