# MultiHop-RAG 上游数据归属

本目录中的 `corpus.json` 和 `MultiHopRAG.json` 是从 [yixuantt/MultiHopRAG](https://huggingface.co/datasets/yixuantt/MultiHopRAG) 的修订 `71ac0d0bd1f951d2d6b70311f7d2ae404e1ffa82` 获取的未修改原始文件。数据集作者为 Yixuan Tang 和 Yi Yang；项目及引用信息见[上游仓库](https://github.com/yixuantt/MultiHop-RAG)。

上游将 **MultiHop-RAG 数据库**标注为 [Open Data Commons Attribution License 1.0（ODC-BY）](https://opendatacommons.org/licenses/by/1-0/)。该许可要求归属说明。ODC-BY 明确区分数据库权利和其中内容的独立版权；`corpus.json` 包含第三方新闻正文，其单篇文章的再分发权并未由这份数据库许可单独确认。将文件纳入本地 Git 记录，不代表第三方文章权利已经核清；公开发布时应另行判断这一点。

固定文件 SHA-256 和验证命令见 [数据合同](../../README.md)。答案与证据标注只供离线评测，在线索引只接收经过字段白名单适配的文章记录。
