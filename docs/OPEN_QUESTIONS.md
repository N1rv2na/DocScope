# DocScope 未决问题

> 仅列尚未确认、需要在对应阶段开始前回答的问题。已确认的范围和技术方向见 [design.md](design.md)、[ARCHITECTURE.md](ARCHITECTURE.md) 与 [ADR](adr/)。这里的 **Assumption** 是待验证的临时设想，不是决策。

| 最迟阶段 | 未决问题 | 当前 Assumption / 决定所需证据 |
|---|---|---|
| M0 | 远程 LLM 采用哪个 Provider、模型与版本？结构化输出、用量记录和错误恢复是否满足有界 Agent？ | **Assumption**：优先试 OpenAI-compatible API；以最小调用、稳定性及 100 元总费用测算决定。 |
| M0 | 本地 Embedding 选哪个英文模型、版本与维度？在当前 CPU 环境下摄取和检索耗时如何？ | **Assumption**：SentenceTransformers 体系可满足 M1；用小样本质量和运行成本验证。 |
| M0 | 固定哪个 Qdrant 服务端/客户端版本，原生全文 BM25、Dense 与 RRF 能否在该组合上完成能力检查？ | **Assumption**：选择支持全文 BM25 的版本；以最小混合查询验证，不改变已确认的单 Qdrant 路径。 |
| M0 | MultiHop-RAG 固定哪个数据版本、如何标识问题与文章、如何划分开发/封存测试集并检查重复问题？ | 需冻结来源、校验值、样本 ID、划分种子和去重结果；公开数据没有可直接采用的独立测试集。 |
| M0 | 标注 `fact` 如何映射到 Chunk；匹配失败、跨 Chunk 事实、指标 K/分母和答案规范化怎样定义？ | 需先用少量样本验证映射和人工复核，再冻结离线评测合同。 |
| M0 | 在 100 元远程 LLM 总预算内，Answer/Agent 固定分层子集、各实验组调用上限和最终报告覆盖量是多少？ | 开发集实测单题 Token/费用后确定；封存测试集不能用于反复调参。 |
| M1 | 文档身份、重传替换的原子性、失败后恢复与旧引用失效提示如何落地？ | **Assumption**：轻量元数据可用 SQLite；以重传无重复、替换/删除后不可检索及可诊断错误验收。 |
| M1 | Chunk 长度/重叠、PDF 页码和 Markdown 章节映射采用什么具体规则？ | **Assumption**：先用可复现的长度/重叠分块；需通过引用定位和开发集验证。 |
| M2 | 英文 BM25 文本处理、RRF 参数、本地 Cross-Encoder 模型与 Top-N 选什么配置？ | 由冻结开发集上的文章级/片段级检索指标、CPU 时延和错误案例决定。 |
| M3 | LLM 证据覆盖输出、无新信息判定和停止阈值的具体合同是什么？ | **Assumption**：最多三轮检索作为起点；以证据依赖样本、拒答与费用回归验证。 |
| M3 | SSE 的事件载荷、断连、重试和重复请求语义怎样冻结？ | 已确定 `stage`、`token`、`citation`、`done`、`error` 类型；需验证正常/错误终态及客户端恢复。 |
| M3 | 人工审查的依赖型样本如何固定，事实依赖和引用支持性由谁、按什么规则复核？ | 需保存第一跳新事实、第二跳查询和来源轨迹；具体样本与审查规程未冻结。 |
| M4 | Checkpointer 版本、完整消息与 Checkpoint 的存储职责、`thread_id` 生命周期、摘要失败恢复如何划分？ | **Assumption**：LangGraph Checkpointer + SQLite；以会话连续性、删除和暂态重置测试决定。 |
