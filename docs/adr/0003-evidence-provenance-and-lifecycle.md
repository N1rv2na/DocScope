# ADR 0003：引用绑定实际 Chunk，文档更新按替换处理

状态：Accepted（设计决策；尚未实现）<br>
依据：[design.md §3.1、§6.1、§6.3](../design.md)、审查决策 Q6、Q9。

## Context

DocScope 的用户价值要求答案能定位到原文。只显示文章名无法保证具体结论有证据；把用户上传文件不断追加到索引，会造成重复或过期内容。文档删除或重传后，历史引用也可能失效。

## Decision

从 M1 起，为文档和 Chunk 保留可追溯身份与源位置。回答只能引用本次实际检索到的 Chunk；程序校验引用 ID，Evaluation 另核查片段是否支持结论。M1 支持上传、索引状态、同一文档重传替换与删除，不建设版本历史。替换或删除后旧内容不再可检索；旧引用失效时明示，不静默转向新材料。导入未完成或失败不得标记为可用。

## Alternatives

- **只允许追加，修改时清空重建**：实现快，但重复 Chunk、过期结果和演示状态污染难控制。
- **正式文档版本历史**：可保留旧引用，但增加存储、UI 与身份语义，超出 M1/M3 范围。
- **仅文章级引用**：易实现，但无法定位 PDF 页码/Markdown 章节及实际支持片段。

## Consequences

- 摄取、检索、回答、UI 和离线评测需共享来源映射；引用 ID 合法与结论受支持必须分开检查。
- 替换/删除与检索可见性的边界是 M1 验收重点；具体原子性方案和 ID 生成规则留给 M1 Issue。
- 已失效的旧引用不能再充当当前证据，页面需要可理解的失效状态。
