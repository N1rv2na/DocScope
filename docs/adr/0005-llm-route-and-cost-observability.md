# ADR 0005：使用外部免费路由组并取消累计金额上限

状态：Accepted（2026-10-26；修订 Q13 与正式 A–E 的 LLM 路由约束）<br>
依据：项目所有者确认将 Magpie `group/docscope-free` 用于真实实验，并取消原先远程 LLM 总费用 100 元人民币上限；DOCS-002 的最小调用记录见 [运行记录](../../evaluation/feasibility/result.md)。

## Context

原设计以 100 元人民币总调用上限控制实验规模，并要求正式 A–E 固定单一模型与渠道。现在计划使用外部 Magpie 免费顺序路由组完成开发和正式实验。组内可能因额度或故障切换成员；虽然三条渠道名义上提供同一模型家族，实际服务实现和输出仍可能有差异。项目仍需公平比较 A–E，并保留 Agent 单次运行的有界停止条件。

## Decision

- 取消 DocScope 远程 LLM **项目级累计金额硬上限**。真实 Token、调用次数、延迟和可获得的实际费用继续逐次记录；未知计价不得写成已确认的零费用。费用测算只报告输入样本与价格假设，不拒绝超过任意累计金额的计划。
- 开发与正式 A–E 均可使用 `group/docscope-free`。正式评测前冻结组成员、顺序路由配置、模型参数、样本 ID 和运行时间窗口；A–E 使用同一配置。逐次保存网关返回的模型 ID，并在可获得时保存实际渠道 ID；无法辨认渠道时记录为未知，不推断成员。
- 报告各实验组的渠道分布和失败/回退情况。若组间分布失衡或渠道不可辨，不宣称严格同模型/同渠道控制的质量差异；可在可识别的匹配样本上补分析。D/E 的相近检索、证据长度和模型调用预算仍须保留。
- LangGraph Agent 的每次运行检索轮数、模型调用数和上下文长度上限继续生效，以保证停止、延迟和可复核性。Magpie 仍是外部网关，DocScope 不实现 Provider 路由层。

## Alternatives

- **保留 100 元总额与单渠道正式评测**：控制费用且便于比较，但与已确认的免费路由组实验计划不符，也把样本量绑定到不适用的旧上限。
- **取消金额上限并完全忽略路由差异**：实施简单，但可能把渠道切换误判为检索或 Agent 的效果。
- **在 DocScope 内实现自己的模型池和路由器**：有更多控制权，但增加与核心 RAG 能力无关的复杂度，并与外部 Magpie 边界冲突。

## Consequences

- 原 DOCS-002 `budget` 命令改为无金额上限的 `cost` 测算；旧 100 元门槛与预留额不再用于验收。
- 答案/Agent 固定分层子集仍用于公平对照与复现，可根据评测质量和运行时间决定覆盖量，但必须在封存测试集运行前冻结。
- 免费渠道的额度耗尽、429、流式中断及回退行为尚未完整验证；正式评测若出现切换，需要保存失败和实际路由证据。网关无法暴露渠道 ID 时，报告须明确比较的控制边界。
