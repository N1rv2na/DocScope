# ADR 0004：隔离评测标签并同时报告实际与等预算对照

状态：Accepted（DOCS-001 数据隔离与划分、DOCS-008–010 检索对照已实现；回答和 Agent 对照尚未实现）<br>
依据：[design.md §7](../design.md)、审查决策 Q2、Q6、Q7、Q10、Q12–Q15。

> 2026-10-26 更新：下文提及的项目级 100 元累计金额上限已由 [ADR 0005](0005-llm-route-and-cost-observability.md) 取消；固定评测子集、逐题用量记录和 D/E 相近单次运行预算仍有效。正式 A–E 可以使用冻结配置的免费路由组，实际渠道差异须披露。

## Context

MultiHop-RAG 提供文章、问题、参考答案和支持 `fact`，但没有 DocScope 的 Chunk ID；公开数据只有单一划分。多文档问题未必要求查询依赖前跳证据。Agent 比单轮 RAG 可能消耗更多调用，直接比较答案正确率会混淆动态策略与预算收益；远程 LLM 总费用还受 100 元人民币上限约束。

## Decision

文章正文进入检索语料；答案、支持事实和不可回答标签只供离线 Evaluation。项目自行冻结开发集和封存测试集，不在测试集调参。分别报告文章级召回与支持事实片段级覆盖；`null_query` 不进入有证据召回指标分母。MultiHop-RAG 做总体对照，另用人工审查的依赖型样本证明动态第二跳，并用自建无证据问题补足拒答场景。

全部问题参与离线检索运行；Answer/Agent 与消融使用评测前固定的分层子集。对 A–E 报实际质量、延迟、Token、调用量和费用；对单轮规划 D 与动态迭代 E 再做相近检索与证据预算的对照。工程完成与效果提升分开验收，只有实测支持时才声称提升。

## Alternatives

- **同一批问题反复调参并报告最终分数**：省事，但结果有测试集污染风险。
- **只报文章级或只用官方文本匹配指标**：无法判断最终 Chunk 是否含有支持事实，匹配误差也难解释。
- **仅比较自然运行的最终正确率**：无法区分多花预算与动态检索决策的贡献。
- **全部配置跑全量回答评测**：覆盖广，但可能超过既定 LLM 费用上限。

## Consequences

- 需要固定数据版本、样本 ID、划分、证据映射、指标分母和逐题结果；映射失败须单列。
- 等预算条件若无法完全匹配，报告差异，不宣称严格等预算。
- 回答与 Agent 指标只代表公开声明的固定子集，不能写成全量 Benchmark 成绩。
- 若 Agent 没有优于 Baseline，仍可完成工程验收，但报告和简历必须如实展示误差与限制。
