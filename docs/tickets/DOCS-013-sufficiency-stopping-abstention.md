# DOCS-013 — 完成证据充分性、停止、拒答与引用校验

**Status:** ready-for-agent
**Priority:** P0
**Planned milestone:** M3

## Background

动态检索已有第二跳，但仍需确定何时停止及证据不足时如何避免虚构结论。

## Goal

充分、缺失、重复、无新证据与预算耗尽场景均有可解释、有界结果。

## Scope

- 规则约束加 LLM 缺失事实判断与结构化输出校验。
- 停止原因、拒答和引用 ID 校验。

## Out of Scope

新检索策略、长期记忆和效果提升承诺。

## Technical Approach

程序执行预算和引用规则；LLM 只判断证据覆盖及下一目标，在开发集冻结轮数、调用和上下文上限。

## Implementation Steps

1. 固定充分性结果合同。
2. 实现各停止分支和拒答。
3. 注入异常模型输出与无证据场景。

## Acceptance Criteria

- [ ] 充分证据时可停止回答；必要事实缺失且预算耗尽时拒答。
- [ ] 重复、无新证据及预算耗尽各有停止原因，调用不超限。
- [ ] 不合格模型输出不能触发无限重试。
- [ ] 未检索或不存在引用 ID 不出现在成功答案。

## Tests & Validation

停止分支集成测试、异常结构化输出与引用注入测试。

## Dependencies

- DOCS-012 — 实现依赖前跳证据的有界第二跳检索

## Deliverables

充分性/停止路径、拒答/引用校验、测试和预算配置。
